# Scope and implementation

Directed synchronous min-flooding for at most 12 nodes and 32 edges. Reliable links deliver messages every round. Enumerate baseline and optionally every single pre-start node/edge outage; simulate n-1 rounds and compare to an independent reachability oracle. No asynchronous consensus theorem, runtime crash recovery, Byzantine faults or deployment.

The code implements a bounded reference method, not a new universal theory. Source and method versions, declared inputs and explicit limitations must accompany downstream claims. Domain test success does not substitute for independent reproduction. Changes to captured evidence reopen dependent claims through the ResearchOS controller.
